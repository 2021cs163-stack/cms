## Fixes made during the check

- Teacher course assignments now clear when removed. Because every class requires a teacher, removing a class assignment gives a clear instruction to reassign the class first instead of silently retaining it. Database changes remain atomic on validation failure.

- Teacher password-reset links use the requesting allowed frontend origin, including when `APP_ORIGIN` contains multiple URLs. Missing origins produce an explicit error for non-browser reset requests.

- Added repeatable bundling for the standalone Supabase dashboard deployment files.
